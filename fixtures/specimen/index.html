Introduction

This manual demonstrates BelType's print-layout features: a generated table of contents with real page numbers, and running headers and footers.

Purpose

The purpose is to validate that headers, footers, and TOC all render correctly under Paged.js pagination. Every key this document may carry is catalogued in a later chapter. Install steps live in .

Scope

This fixture exercises print layout: a generated Contents with real page numbers, and running headers and footers. Page geometry and the running headers/footers are a small author stylesheet (specimen.css, @page and its margin boxes); the typographic look is BelType's default addendum. A reusable look would be a spec — a directory of real CSS, addressed by path.

Installation

Installation instructions would go here, spanning enough content to push later chapters onto subsequent pages so the table of contents shows varied page numbers.
